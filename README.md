# Express - Sequelize ORM boilerplate

An Express.js - Sequelize ORM boilerplate
## Run Locally

Clone the project

```bash
  git https://github.com/dj0nny/express-sequelize-boilerplate
```

Go to the project directory

```bash
  cd express-sequelize-boilerplate
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```

## Environment Variables

To run this project, you may need to edit the following environment variables to your .env file

`DATABASE_URL`

## Sequelize Configuration

For this boilerplate, the default database client is __Sqlite__.

You can add your own database driver by following [this section](https://sequelize.org/docs/v6/getting-started/#installing) and [this section](https://sequelize.org/docs/v6/getting-started/#connecting-to-a-database).


## Tech Stack

Node.js, Express, Sequelize, Sqlite
